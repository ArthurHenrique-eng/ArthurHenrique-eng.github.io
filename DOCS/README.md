Os arquivos `original-*` e `marca-*` preservam as identidades anteriores. `marca-lumora.webp` continua na galeria, conforme o Canva. Talentix integra os sete projetos; sua logo está organizada aqui, enquanto a galeria mantém as cinco marcas da referência.

As cópias WebP mantêm o desenho e a transparência dos arquivos fornecidos, em resoluções apropriadas para a página. Os originais SVG/PNG ficam disponíveis para outras aplicações. O nome `VSCODE2022.svg` foi mantido, embora a imagem represente o Visual Studio 2022; o texto alternativo identifica a ferramenta corretamente.

O ícone Lattes é apresentado como imagem, pois não foi fornecida a URL do currículo pessoal. Para ativá-lo, substitua os dois elementos `.profile-socials__lattes` em `index.html` por links para a URL confirmada.
